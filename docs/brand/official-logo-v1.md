# Zobdino Official Logo v1

The canonical Zobdino brand mark is stored at:

- `public/brand/zobdino-logo.png`
- `public/brand/zobdino-icon-512.png`
- `public/brand/zobdino-icon-192.png`
- `public/favicon.png`
- `public/apple-touch-icon.png`

## Product usage

The official logo is used by the website header and footer. The official favicon and Apple touch icon are registered through the Next.js application metadata.

## Brand principle

Zobdino uses a simple, flat and minimal visual identity. Product surfaces should use the canonical assets above rather than legacy logo or mark files.
