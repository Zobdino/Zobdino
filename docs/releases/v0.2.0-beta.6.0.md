# Zobdino v0.2.0-beta.6.0 — Prerelease Candidate

Tracking issue: #159

Target: current verified `main`

## Why this prerelease exists

The previous published prerelease is `v0.2.0-beta.5.1.20` from 2026-08-18. Since then, multiple release-worthy product, voice, TTS-resume, and delivery-governance changes have been merged and verified but not represented in GitHub Releases. This candidate closes that versioning gap without claiming production media promotion that has not happened yet.

## Included merged changes

- PR #144 — preview catalog/data wiring and audio-player integration path.
- PR #147 — Atomic Habits production cover repair.
- PR #150 — canonical approved voice contract for Sulafat and Schedar, with player metadata support and legacy-audio distinction.
- PR #153 — durable free-tier TTS checkpoint state and digest verification for resume safety.
- PR #155 — durable quota-paused TTS failure state and machine-readable resume metadata.
- PR #157 — repository-native delivery governance: Issue → Branch → Commit → Draft PR → CI → Code Review → Ready → Squash Merge → Post-merge verification → Release obligation.
- PR #158 — automatic post-failure classification of dual-voice production runs into resumable quota-paused artifacts.

## Product impact

This prerelease versions the product/runtime contracts now present on `main`:

- preview product layer is connected to catalog data and audio-player flow;
- approved voice identities are explicit and legacy audio is no longer presented as final approved media;
- free-tier TTS generation can preserve durable checkpoints across quota failures;
- quota exhaustion is represented as an explicit resumable state instead of only a generic failure;
- every release-worthy implementation slice now carries a mandatory GitHub delivery/release obligation.

## Explicit non-claim

This prerelease does **not** claim that newly generated Sulafat/Schedar Atomic Habits production audio has been completed, published, or promoted to the live player. Production audio promotion remains blocked until a real dual-voice production batch succeeds, its artifacts pass QA, and a separate media/player release is verified in production.

## Safety and rollback boundary

- No database migration is introduced by this release candidate.
- No payment or authentication behavior is changed.
- Existing published audio remains untouched by the quota-resume changes.
- The release can be rolled back at the application/version level without deleting generated checkpoints or published media.
- Media promotion remains fail-closed until verified immutable assets exist.

## Next controlled step

After this prerelease is actually published in GitHub Releases, execute the real Atomic Habits dual-voice production path with Sulafat and Schedar, validate generated artifacts, then open a separate issue/PR/release for player promotion and production verification on `zobdino.ir`.
