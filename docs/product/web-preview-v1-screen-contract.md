# Zobdino Web Preview v1 — Screen Contract

## Goal
Define the first user-visible preview experience.

## Screens

### Catalog Page
- Show available preview episodes
- Display title, cover, language, status

### Book Detail Page
- Title
- Summary preview
- Episode metadata
- Voice options

### Audio Preview Player
- Play/pause
- Voice selection
- Duration
- Preview-only access
