# Zobdino Preview UI Contract v1

## Goal
Define the first user-facing preview experience for Zobdino.

## Components

### BookCard
- cover
- title
- language
- preview status

### BookDetail
- title
- summary preview
- episode metadata
- voice options

### AudioPlayer
- play/pause
- selected voice
- preview duration
- artifact reference
